  <name>Task 1: Cost ledger aggregation, threshold API routes, and unit tests</name>
  <files>server/costLedgerRoutes.ts, server/__tests__/costLedger.test.ts</files>
  <action>
  Create `server/costLedgerRoutes.ts` with an Express Router. Use raw SQL (pool.query) for aggregation queries.

  Endpoints:

  1. **GET /properties/:id/costs** -- Per-property cost ledger
     - Two queries run in parallel:
       a. Maintenance costs: SELECT from work_order JOIN maintenance_request WHERE mr.property_id=$1 AND wo.invoice_amount IS NOT NULL, ORDER BY wo.created_at DESC
       b. Compliance costs: SELECT from property_certification WHERE property_id=$1 AND cost IS NOT NULL, ORDER BY inspection_date DESC
     - Return JSON:
       ```json
       {
         "maintenance": { "items": [...], "total": 12500 },
         "compliance": { "items": [...], "total": 3500 },
         "grandTotal": 16000
       }
       ```
     - All amounts in pence (frontend converts to display)

  2. **GET /landlords/:id/costs** -- Per-landlord cost ledger (all properties)
     - Query: Get all properties WHERE landlord_id=$1, then aggregate costs per property
     - Use a single query with GROUP BY for efficiency:
       ```sql
       SELECT p.id AS property_id, p.address,
         COALESCE(SUM(wo.invoice_amount), 0) AS maintenance_total,
         COALESCE(cert_costs.total, 0) AS compliance_total
       FROM properties p
       LEFT JOIN maintenance_request mr ON mr.property_id = p.id
       LEFT JOIN work_order wo ON wo.maintenance_request_id = mr.id AND wo.invoice_amount IS NOT NULL
       LEFT JOIN LATERAL (
         SELECT COALESCE(SUM(cost), 0) AS total
         FROM property_certification pc WHERE pc.property_id = p.id AND pc.cost IS NOT NULL
       ) cert_costs ON true
       WHERE p.landlord_id = $1
       GROUP BY p.id, p.address, cert_costs.total
       ORDER BY p.address
       ```
     - Return JSON:
       ```json
       {
         "properties": [
           { "propertyId": 1, "address": "...", "maintenanceTotal": 5000, "complianceTotal": 2000 }
         ],
         "grandTotal": 7000
       }
       ```

  3. **GET /properties/:id/cost-threshold** -- Get threshold config for a property
     - Return threshold or null if not set

  4. **PUT /properties/:id/cost-threshold** -- Set/update threshold for a property
     - Accept: annualLimit (integer, pence), notificationEmail (string)
     - UPSERT: INSERT ... ON CONFLICT (property_id) DO UPDATE
     - Note: property_cost_threshold needs a UNIQUE constraint on property_id. Add it via direct SQL if not present: `ALTER TABLE property_cost_threshold ADD CONSTRAINT uq_property_cost_threshold_property_id UNIQUE (property_id);`
     - Return the threshold record

  5. **DELETE /properties/:id/cost-threshold** -- Remove threshold
     - DELETE FROM property_cost_threshold WHERE property_id=$1

  6. **POST /costs/check-thresholds** -- Check all thresholds and send alerts (called by cron or manually)
     - For each threshold in property_cost_threshold:
       a. Calculate current year's total costs (maintenance + compliance) for that property
       b. If total >= annualLimit AND (last_alert_sent IS NULL OR last_alert_sent < NOW() - INTERVAL '30 days'):
          - Send email via emailService to notificationEmail with: property address, current spend, threshold, breakdown
          - Update last_alert_sent = NOW()
     - Return count of alerts sent
     - Email-only alerts per user decision (NOT in-CRM bell)

  Export `costLedgerRouter`.

  Then create `server/__tests__/costLedger.test.ts` with unit tests:
  - Test COST-01: "aggregates maintenance costs from work_order.invoice_amount" -- verify costLedgerRoutes.ts source code contains SQL that JOINs work_order with maintenance_request and references invoice_amount (static analysis)
  - Test COST-02: "aggregates compliance costs from property_certification.cost" -- verify costLedgerRoutes.ts source code contains SQL referencing property_certification and cost column (static analysis)
  - Test COST-03: "threshold email uses emailService not notification table" -- verify costLedgerRoutes.ts POST /costs/check-thresholds handler imports/uses emailService.sendEmail and does NOT insert into notification table for threshold alerts (static analysis)
  - Use `import { describe, it, expect } from 'vitest'` and `import fs from 'fs'` for static analysis approach
