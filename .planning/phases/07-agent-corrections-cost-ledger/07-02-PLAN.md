<task type="auto">
  <name>Task 1: Offer management API routes with notification and email</name>
  <files>server/offerRoutes.ts</files>
  <action>
  Create `server/offerRoutes.ts` with an Express Router. Use raw SQL (pool.query) following pmWorkflowRoutes pattern.

  Endpoints:

  1. **GET /offers** -- List all offers with optional filters
     - Query params: propertyId, status, dateFrom, dateTo
     - JOIN with properties table to include property address
     - ORDER BY created_at DESC
     - Returns array of offers with property address

  2. **GET /offers/:id** -- Get single offer with full details
     - JOIN properties for address, JOIN users for decision_by name

  3. **POST /offers** -- Create a new offer (used by API/manual entry, agent uses tool directly)
     - Accept all propertyOffers fields
     - After INSERT:
       a. Look up property's agent_id from properties table
       b. INSERT into notification table: title="New offer: [formatted amount] on [address]", body with buyer details, type='info', linkUrl='/crm/offers'
       c. Send email via emailService to the assigned agent's email (look up from users table by agent_id). Email includes: offer amount, buyer name, buyer position, chain status, conditions, proposed completion date, and a direct CRM link `${process.env.APP_URL || 'http://localhost:5000'}/crm/offers`
       d. If no agent_id on property, fall back to property_manager_id, then to first user with role='admin'
     - Return the created offer

  4. **PATCH /offers/:id/status** -- Update offer status
     - Accept: status (accepted/rejected/withdrawn), rejectionReason (optional), counterOfferAmount (optional), finalAgreedAmount (optional)
     - Set decisionDate=NOW(), decisionBy=req.user.id
     - If status=accepted and counterOfferAmount provided, set counterOfferDate=NOW()
     - Return updated offer

  5. **GET /properties/:id/offers** -- List offers for a specific property
     - Same as GET /offers but filtered by propertyId
     - ORDER BY created_at DESC

  Format monetary amounts for display: divide pence by 100, format with GBP symbol.

  Email template (HTML):
  - Subject: "New Offer Received - [property address]"
  - Body: Professional HTML email with offer amount (formatted GBP), buyer name, buyer position, chain details, conditions, proposed completion date, and a "View in CRM" button linking to /crm/offers
  - Use inline styles for email compatibility

  Import pool from '../db', import emailService pattern from existing usage.
  </action>

  </verify>
