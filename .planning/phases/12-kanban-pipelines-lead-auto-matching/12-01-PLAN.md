**4. Create server/leadMatchingService.ts** with these exports:

- `findMatchingLeads(propertyId: number, pool: Pool): Promise<MatchResult[]>` -- Queries the `lead` table for leads matching the property. Matching logic:
  - For sales properties (`is_rental = false`): match leads where `lead_type IN ('purchase', 'both')`
  - For rental properties (`is_rental = true`): match leads where `lead_type IN ('rental', 'both')`
  - Only match leads with `status NOT IN ('converted', 'lost')` (active leads only)
  - Score calculation (0-100):
    - Budget match (+40): property price/rentAmount falls within lead's min_budget..max_budget range (if both null, skip -- don't add points)
    - Bedrooms match (+25): exact match on preferred_bedrooms (null preferred_bedrooms = skip, don't add)
    - Area match (+25): property postcode starts with any of lead's preferred_areas entries (case-insensitive prefix match, e.g. 'SW2' matches 'SW2 1AB')
    - Property type match (+10): exact match on preferred_property_type vs property_type
  - Threshold: only return leads with score >= 50
  - Use raw SQL with `pool.query()` consistent with crmRoutes.ts patterns

- `createMatchesForProperty(propertyId: number, pool: Pool): Promise<number>` -- Calls findMatchingLeads, inserts rows into lead_property_match with status='pending', returns count of matches created. Skip leads that already have a match for this property (prevent duplicates with: `AND NOT EXISTS (SELECT 1 FROM lead_property_match WHERE lead_id = l.id AND property_id = $propertyId)`).

- `approveMatch(matchId: number, userId: number, pool: Pool): Promise<void>` -- Updates match status to 'approved', sets approved_by and approved_at. Then queries the lead's email and the property's title/address/price/bedrooms/images[0] and sends a property details email using `emailService.sendEmail(leadEmail, subject, htmlBody)` imported from `server/emailService.ts`. After send succeeds, update status to 'sent', sent_at = NOW(), sent_via = 'email'. The email HTML should be a simple branded template with property image, title, address, price formatted as GBP (divide pence by 100), bedrooms count, and a "View Property" link to `${process.env.APP_URL || 'https://johnbarclay.co.uk'}/property/${propertyId}`.

- `dismissMatch(matchId: number, pool: Pool): Promise<void>` -- Updates match status to 'dismissed'.

All monetary comparisons must be pence-to-pence (both leads and properties store values in pence).
