  <name>Task 1: Add API endpoints for property knowledge base data</name>
  <files>server/crmRoutes.ts</files>
  <action>
Add 4 new endpoints to server/crmRoutes.ts for property knowledge base data. CRITICAL: Grep shared/schema.ts for exact column names before writing any query.

1. **GET /properties/:id/knowledge-base** -- Aggregated KB view
   - Returns { certifications: [...], systems: [...], recentMaintenance: [...] }
   - Query propertyCertifications WHERE propertyId = :id, ordered by expiryDate ASC
   - Query propertySystemsInventory WHERE propertyId = :id, ordered by systemType
   - Query maintenanceTickets WHERE propertyId = :id, ordered by createdAt DESC, LIMIT 20
   - Requires authentication (use existing requireAgent middleware pattern)

2. **GET /properties/:id/systems-inventory** -- Systems inventory CRUD read
   - Returns array of systems inventory records for property
   - Requires authentication

3. **POST /properties/:id/systems-inventory** -- Create systems inventory entry
   - Accepts body: { systemType, make?, model?, serialNumber?, installedDate?, installedBy?, contractorId?, warrantyExpiryDate?, lastServiceDate?, nextServiceDue?, serviceIntervalMonths?, location?, notes?, specifications? }
   - Validates with Zod (use insertPropertySystemsInventorySchema or create a specific one)
   - Inserts into propertySystemsInventory with propertyId from URL
   - Returns the created record

4. **PUT /properties/:id/systems-inventory/:systemId** -- Update systems inventory entry
   - Accepts partial body (same fields as POST)
   - Updates the record WHERE id = :systemId AND propertyId = :id
   - Returns the updated record

Place these endpoints in the property management section of crmRoutes.ts. Follow existing error handling pattern: try/catch with res.status(500).json({ error: message }).
