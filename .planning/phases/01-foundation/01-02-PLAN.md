   - Maps to NormalizedMessage with channel="sms"

2. Create server/agents/channels/adapters/whatsappAdapter.ts:
   - Class WhatsAppAdapter with method normalize(payload: any): NormalizedMessage
   - Extracts from Twilio WhatsApp webhook body: From (strips "whatsapp:" prefix), Body, MessageSid, To
   - Maps to NormalizedMessage with channel="whatsapp"

3. Create server/agents/channels/gateway.ts:
   - Class ChannelGateway with:
     - Private adapters Map<CommunicationChannel, Adapter> -- registers sms and whatsapp adapters
     - processInbound(channel: CommunicationChannel, payload: unknown): Promise<InboundResult>
       - Normalize via adapter
       - Resolve contact via contactResolver
       - Find or create conversation via conversationStore
       - Store inbound message
       - Return { conversationId, messageId, contact, isNewConversation }
     - NOTE: Do NOT route to agents in this plan. That wiring happens in Phase 2. The gateway's job here is normalize -> resolve -> thread -> store.
   - Export singleton: `export const channelGateway = new ChannelGateway()`
