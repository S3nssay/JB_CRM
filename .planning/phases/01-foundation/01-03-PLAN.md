1. Create server/agents/tools/types.ts:
```typescript
import { z } from 'zod';
import { AgentType, CommunicationChannel } from '../types';

export interface ToolDefinition<TInput extends z.ZodType = z.ZodType, TOutput extends z.ZodType = z.ZodType> {
  name: string;
  description: string;
  inputSchema: TInput;
  outputSchema: TOutput;
  permissions: AgentType[];
  tier: 'autonomous' | 'confirm' | 'human_only';
  execute: (input: z.infer<TInput>, context: ToolContext) => Promise<z.infer<TOutput>>;
}

export interface ToolContext {
  agentType: AgentType;
  conversationId: number | null;
  contactId: number | null;
  channel: CommunicationChannel;
}

export interface ToolInvocationResult {
  output: unknown;
  durationMs: number;
  toolName: string;
}
```

2. Create server/agents/tools/registry.ts:
   - Class ToolRegistry:
     - private tools: Map<string, ToolDefinition>
     - register(tool: ToolDefinition): void -- stores tool by name
     - invoke(name: string, rawInput: unknown, context: ToolContext): Promise<ToolInvocationResult>
       - Lookup tool by name (throw if not found)
       - Check context.agentType is in tool.permissions (throw if not)
       - Parse input through tool.inputSchema (Zod validation)
       - Execute tool.execute(parsedInput, context)
       - Parse output through tool.outputSchema
       - Return { output, durationMs, toolName }
       - Audit logging is NOT wired here -- Plan 04 will import auditLogger and add the logToolCall() call into this method
     - getOpenAITools(agentType: AgentType): array of OpenAI function tool objects
       - Filter tools by permission for this agentType
       - Convert each tool's inputSchema from Zod to JSON Schema manually (use zodToJsonSchema helper or manual conversion -- keep it simple, support z.object with z.string/z.number/z.boolean/z.enum/z.array/z.optional)
       - Return array of { type: "function", function: { name, description, parameters } }
     - getToolNames(): string[] -- list all registered tool names
     - hasTool(name: string): boolean
   - Export singleton: `export const toolRegistry = new ToolRegistry()`
   - At bottom of file, import and register all 5 tool definitions (after they exist)
