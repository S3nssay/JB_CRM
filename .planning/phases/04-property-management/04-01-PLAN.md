<objective>
Build the Property Management specialist agent core: fault intake from any text channel, property knowledge base triage, rules-based emergency classification, and maintenance ticket creation.

Purpose: The PM agent receives fault reports from tenants, automatically resolves their property, queries the knowledge base for relevant system information (heating type, warranty status, last service date), classifies urgency using code-level rules, and creates a maintenance ticket with full AI triage data. This replaces manual staff intake for routine maintenance.

Output: Working pmAgent wired into Supervisor handoffs, with emergency rules engine and tenant-to-property resolution, tested.
</objective>

       - Export interface `EmergencyClassification { urgency: 'emergency' | 'urgent' | 'routine' | 'low'; score: number; reasoning: string; isEmergency: boolean; }`
       - Export function `classifyUrgency(description: string, category: string, systemInfo: any | null, currentDate?: Date): EmergencyClassification`
       - Emergency keyword patterns (regex, case-insensitive):
         * Gas: /gas\s*leak|smell(ing)?\s*gas|carbon\s*monoxide|co\s*alarm/i -> emergency, score 10
         * Flood: /burst\s*pipe|flood(ing)?|water\s*pour(ing)?|ceiling\s*leak(ing)?|water\s*coming\s*(through|in)/i -> emergency, score 10
         * Heating (winter = Oct-Mar): /no\s*heating|heating\s*(broken|not\s*working|off|failed)|boiler\s*(not\s*working|broken|failed|off)/i AND winter -> emergency, score 9; same pattern outside winter -> urgent, score 7
         * Security: /break[\s-]*in|door\s*(won't|can't|cannot)\s*lock|window\s*(smashed|broken|shattered)|lock\s*(broken|jammed)/i -> emergency, score 9
         * Electrical danger: /electric(al)?\s*shock|sparking|burning\s*smell|exposed\s*wir(e|ing)/i -> emergency, score 10
         * Hot water (check if vulnerable): /no\s*hot\s*water/i -> urgent, score 6 (upgrade to emergency if vulnerable tenant in systemInfo)
       - Non-emergency patterns:
         * Urgent: /boiler|electrical\s*fault|broken\s*lock|pest|infest/i (not already matched) -> urgent, score 5-6
         * Routine: /drip(ping)?|minor|appliance|washing\s*machine|dishwasher|oven/i -> routine, score 3
         * Low: /cosmetic|paint(ing)?|scuff|scratch|decoration/i -> low, score 1-2
       - Default: routine, score 3 (if no patterns match)
       - Function is pure (no DB calls) -- takes date as parameter for testability
