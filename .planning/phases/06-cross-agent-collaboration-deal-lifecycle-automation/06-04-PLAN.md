<interfaces>
<!-- API endpoints from Plan 02 -->

Deal API:
```
GET  /api/crm/deals?status=active&dealType=letting  -> Deal[]
GET  /api/crm/deals/:id                              -> { deal, steps, events }
GET  /api/crm/deals/:id/events?limit=50&offset=0     -> DealEvent[]
POST /api/crm/deals/:id/pause   { reason }           -> Deal
POST /api/crm/deals/:id/resume                       -> Deal
POST /api/crm/deals/:id/cancel  { reason }           -> Deal
POST /api/crm/deals/:id/steps/:stepId/skip           -> DealStep
POST /api/crm/deals/:id/steps/:stepId/complete        -> DealStep
```

Notification API:
```
GET  /api/crm/notifications?unreadOnly=true           -> Notification[]
GET  /api/crm/notifications/unread-count              -> { count }
GET  /api/crm/notifications/stream                    -> SSE event stream
POST /api/crm/notifications/:id/read                  -> { success }
POST /api/crm/notifications/read-all                  -> { success }
```
</interfaces>

1. Create client/src/hooks/use-notifications.ts:
   - useNotifications() hook:
     - State: notifications array, unreadCount
     - On mount: fetch initial notifications via GET /api/crm/notifications and unread count via GET /api/crm/notifications/unread-count
     - Open EventSource to /api/crm/notifications/stream with withCredentials: true
     - On SSE message: parse JSON, prepend to notifications array, increment unreadCount
     - On SSE error: log warning (EventSource auto-reconnects)
     - Cleanup: close EventSource on unmount
     - markAsRead(id): POST /api/crm/notifications/:id/read, decrement unreadCount, update notification in array
     - markAllAsRead(): POST /api/crm/notifications/read-all, set unreadCount to 0, mark all as read in array
     - Return { notifications, unreadCount, markAsRead, markAllAsRead }

2. Create client/src/components/NotificationBell.tsx:
   - Bell icon (Bell from lucide-react) in CRM header

     - Each notification: icon by type, title, body, relative timestamp (e.g., "2 min ago")
     - Unread notifications have subtle background highlight
