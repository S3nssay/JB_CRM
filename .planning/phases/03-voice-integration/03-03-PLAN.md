<objective>
Call lifecycle handling: start, transcript threading into Conversation Store on end, filler speech patterns (configured in Plan 01), latency optimisation.

Purpose: Completes the voice integration by handling what happens after a call ends. The end-of-call-report webhook contains the full transcript which needs to be stored in the ConversationStore (same table as text channel messages) so voice conversations appear alongside WhatsApp/SMS/email threads in the CRM. Post-call actions (SMS confirmation, follow-up scheduling, escalation logging) mirror the text-channel patterns from Phase 2.

Output: Full call lifecycle handling from start to end, with transcripts threaded in ConversationStore, post-call confirmations sent, and escalation records created for human transfers.
</objective>

       - Import: contactResolver, conversationStore, messageSender, escalationService, auditLogger, handlePostActions
       - Import types: VapiEndOfCallReport, CallerContext

       - `async function processEndOfCallReport(report: VapiEndOfCallReport, storedContext?: CallerContext | null): Promise<{ conversationId: number; messageCount: number; callerIdentified: boolean }>`:
         a. Extract caller phone from `report.call?.customer?.number`
         b. Extract transcript messages from `report.artifact?.messages` (filter out system messages, keep only role: 'user' and role: 'assistant')
         c. Extract call metadata: `{ callId: report.call?.id, startedAt: report.call?.startedAt, endedAt: report.call?.endedAt, summary: report.analysis?.summary }`

         d. Resolve caller identity:
            - If storedContext provided (from activeCallContexts): use it directly
            - Else if phone exists: `contactResolver.resolve(phone, 'phone')`
            - Else: create unknown contact with identifierValue = 'unknown-voice-caller'

         e. Find or create conversation:
            - `conversationStore.findOrCreateConversation(contact, 'phone')`

         f. Store each transcript message:
            - For each message in transcript (in chronological order):
              * direction = message.role === 'user' ? 'inbound' : 'outbound'
              * agentType = message.role === 'assistant' ? 'supervisor' : undefined
              * Determine timestamp: use message.time if available, else derive from call startedAt + index offset
              * Build NormalizedMessage: `{ from: direction === 'inbound' ? (phone || 'caller') : 'agent', body: message.content, channel: 'phone', timestamp, metadata: { callId: report.call?.id } }`
              * `conversationStore.storeMessage(conversationId, normalizedMsg, direction, agentType)`

         g. Log the call in audit trail:
            ```
            auditLogger.logResponse({
              agentType: 'supervisor',
              conversationId,
              channel: 'phone',
              durationMs: calculateDurationMs(report.call?.startedAt, report.call?.endedAt),
            })
            ```

         h. Return `{ conversationId, messageCount: transcriptMessages.length, callerIdentified: contact.contactId !== 0 }`

       - Export `processEndOfCallReport`
