<objective>
Vapi provider adapter: Squad configuration, receptionist and specialist voice assistants, Twilio SIP webhook forwarding for UK number.

Purpose: Creates the Vapi configuration layer that defines how inbound calls are handled. The Squad configuration tells Vapi which assistant answers first (Sarah the receptionist), what specialist assistants exist (Sales/Alex, Lettings/Jordan, Admin/Sam), and how handoffs work between them. Also defines the Twilio SIP forwarding setup so calls to the UK agency number route to Vapi.

Output: TypeScript configuration builders that generate valid Vapi API JSON, types for all Vapi webhook payloads, and the vapi npm package installed.
</objective>

    - VapiToolCallResult has results array of { toolCallId, result } where both are strings
    - VapiAssistantConfig has name, model, voice, firstMessage, instructions, serverUrl, tools, transferDestinations

  <action>
    1. Run `npm install @vapi-ai/server-sdk` to add the Vapi server SDK.

    2. Create `server/agents/voice/types.ts`:
       - Define `VapiServerMessage` union type covering all webhook message types:
         ```
         type VapiMessageType = 'tool-calls' | 'end-of-call-report' | 'assistant-request' | 'hang' | 'status-update' | 'transfer-destination-request' | 'transcript';
         ```
       - `VapiServerMessage`: `{ message: { type: VapiMessageType; [key: string]: any } }`
       - `VapiToolCall`: `{ id: string; type: 'function'; function: { name: string; arguments: string } }`
       - `VapiToolCallMessage`: `{ type: 'tool-calls'; toolCallList: VapiToolCall[]; call?: { id: string; customer?: { number?: string } } }`
       - `VapiEndOfCallReport`: `{ type: 'end-of-call-report'; artifact?: { messages?: Array<{ role: string; content: string; time?: number }>; transcript?: string }; analysis?: { summary?: string; successEvaluation?: string }; call?: { id: string; startedAt?: string; endedAt?: string; customer?: { number?: string } } }`
       - `VapiToolCallResult`: `{ results: Array<{ toolCallId: string; result: string }> }`
       - `VapiAssistantConfig`: interface for assistant creation covering name, model (provider + model name), voice (provider + voiceId), firstMessage, instructions, serverUrl, tools array, and transferCall destinations
       - `VapiSquadMember`: `{ assistant: VapiAssistantConfig | { assistantId: string }; assistantDestinations?: Array<{ type: 'assistant'; assistantName: string; message: string; description: string }> }`
       - `VapiSquadConfig`: `{ name: string; members: VapiSquadMember[] }`
       - `VapiCustomTool`: `{ type: 'function'; function: { name: string; description: string; parameters: Record<string, any> }; async?: boolean; server?: { url: string } ; messages?: Array<{ type: 'request-start' | 'request-complete'; content: string }> }`
       - Export all types
