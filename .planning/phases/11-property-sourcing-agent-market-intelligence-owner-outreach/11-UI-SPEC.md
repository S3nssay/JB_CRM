## Page Inventory

### Page 1: Sourcing Dashboard (`/crm/sourcing-dashboard`)

**Layout:** Full-width within CRMLayout. Stats row at top, tabbed content below.

**Stats Row (4 cards):**

| Card | Icon | Value Source | Color |
|------|------|-------------|-------|
| Leads Sourced (This Month) | TrendingUp | Count of proactive_leads created this month | bg-[#791E75] |

| Response Rate | MessageCircle | Responded / Sent percentage | bg-[#F8B324] |
| Valuations Booked | Calendar | Count of leads with status "valuation_booked" | bg-[#F8B324]/80 |

**Tab Structure:**

| Tab | Content |
|-----|---------|
| Pipeline | Kanban-style pipeline view with approval workflow |
| Campaigns | Campaign configuration cards with create/edit |
| Performance | Source breakdown table + conversion funnel |

#### Pipeline Tab

**Pipeline stages (horizontal flow):**
1. **New** - Leads identified by monitoring scan
2. **Scored** - AI propensity score assigned
3. **Draft Ready** - Outreach letter/email drafted by Charlie
4. **Awaiting Approval** - Staff review queue (primary interaction point)
5. **Sent** - Outreach dispatched
6. **Responded** - Owner replied
7. **Valuation Booked** - Appointment confirmed
8. **Instructed** - Won (deal created)

**Pipeline card (per lead):**
```
+-----------------------------------------+
| [Source Badge]        [Score: 78/100]    |
| 123 Example Road, W8 5PQ               |
| Owner: J. Smith                          |
| Listed: 142 days (Zoopla)              |
| Channel: Letter + Email                 |
|                                          |
| [Approve]  [Edit Draft]  [Reject]       |
+-----------------------------------------+
```

- Source badge colors: Land Registry = purple outline, Stale Listing = gold outline, Auction = red outline, Planning = blue outline, Competitor = gray outline
- Score displayed as circular progress indicator (small, inline)
- Approve/Reject buttons visible only in "Awaiting Approval" stage
- Card click opens detail slide-over panel (Sheet component)

#### Lead Detail Panel (Sheet)

| Section | Content |
|---------|---------|
| Header | Address, postcode, owner name, source badge, propensity score |
| Property Intel | Ownership duration, last sale price, current estimated value, listing history |
| Outreach Draft | Letter text and/or email text (editable textarea), channel indicators |
| Follow-Up Timeline | Sequence of planned touchpoints with dates and status |
| Activity Log | Chronological list of all actions taken on this lead |
| Actions | Approve Outreach, Edit Draft, Reject, Schedule Valuation, Add Note |

## Interaction Patterns

### Pipeline Drag (Future Enhancement - Not Phase 11)
Pipeline cards are NOT draggable in Phase 11. Stage transitions happen via action buttons only (Approve moves from Draft Ready to Sent, etc.). Drag-and-drop deferred to future iteration.

### Approval Workflow
1. Staff sees leads in "Awaiting Approval" column
2. Click card to open Sheet detail panel
3. Review/edit outreach draft in Textarea
4. Click "Approve Outreach" (primary purple button) or "Reject Lead" (destructive outline button)
5. Toast confirmation appears
6. Card moves to next stage (Sent) or disappears (Rejected)

### Campaign CRUD
1. "Create Campaign" button (purple, top-right of Campaigns tab)
2. Dialog opens with form fields
3. Validation via react-hook-form + zod
4. Submit creates campaign, toast confirms
5. Campaign card appears in grid
6. Edit via card's Edit button (same dialog, pre-populated)
7. Delete via card's Delete button (confirmation dialog first)

### Search & Filter
- Search input at top of Pipeline tab (filters by address, owner name, postcode)
- Source filter dropdown (All Sources, Land Registry, Stale Listings, Auctions, Planning, Competitor)
- Status filter tabs are the pipeline stages themselves (clicking a stage column header scrolls to it)
