Create `server/agents/sdk/headOfPMTools.ts` with 7 SDK tools using the established pattern from tools.ts (import { tool } from '@openai/agents', zod4, lazy pool import).

Tools to create:

1. `queryPortfolioOverviewTool` -- Takes landlordId. Queries properties (is_managed=true), property_certification (grouped by property), maintenance_request (open tickets per property), arrears (active per property), tenancy (active/pending per property). Uses Promise.all for parallel queries. Returns JSON with propertyCount, properties, complianceByProperty, maintenanceByProperty, arrearsByProperty, tenancies.

2. `queryPropertyHealthTool` -- Takes propertyId. Returns compliance status (certification_type, expiry_date, health flag: expired/expiring_soon/valid), active maintenance tickets (id, title, status, priority, created_at), active arrears (id, amount_outstanding, status, tenant_name), current tenancy (id, status, start_date, end_date, rent_amount). Uses Promise.all.

3. `queryComplianceStatusTool` -- Takes optional landlordId or propertyId. Returns all certifications with expiry health flag, grouped by property. If landlordId: all properties for that landlord. If propertyId: just that property.

4. `queryMaintenanceActivityTool` -- Takes optional landlordId or propertyId, optional dateRange (days, default 30). Returns maintenance requests within date range with status counts and details.

5. `queryArrearsOverviewTool` -- Takes optional landlordId or propertyId. Returns active arrears cases with tenant name, amount outstanding, days overdue, last contact date from audit_log.

6. `queryTenancyTimelineTool` -- Takes optional landlordId or propertyId. Returns tenancies with start_date, end_date, status, rent_amount, tenant_name. Highlights upcoming renewals (end_date within 90 days).

7. `lookupLandlordPortfolioTool` -- Takes phone or email string. Queries landlords table to find matching landlord by phone, mobile, or email. Returns landlord id, name, email, and property count. This is the entry point for inbound landlord conversations.

IMPORTANT: Before writing any SQL, grep shared/schema.ts for the exact table and column names for: property_certification (or property_certificate), maintenance_request, arrears, tenancy, landlords, properties. Use ONLY the exact names found in schema.

All tools follow the lazy import pattern: `const { pool } = await import('../../db');`
