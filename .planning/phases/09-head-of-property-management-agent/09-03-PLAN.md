  <action>
Create `server/pmOverviewRoutes.ts` with an Express Router exporting `pmOverviewRouter`. Use the same requireAgent middleware pattern from pmWorkflowRoutes.ts.

Three endpoints:

1. `GET /pm-overview/compliance-alerts`
   - Query property_certification (check exact table name in schema.ts) for certs expiring within 30 days or already expired.
   - JOIN properties for address, JOIN landlords for name.
   - Return: `{ expired: [...], expiringSoon: [...], totalProperties: N, compliantProperties: N }`
   - Each cert record: property_id, property_address, certification_type, expiry_date, landlord_name, urgency ('expired' | 'expiring_soon').

2. `GET /pm-overview/portfolio-health`
   - For all managed properties (is_managed = true), calculate health score per property:
     - Start at 100
     - -20 per expired cert
     - -10 per cert expiring within 30 days
     - -5 per open maintenance ticket (status NOT IN ('completed', 'cancelled'))
     - -15 per active arrears case
     - -25 if no active tenancy (vacant)
   - Use Promise.all for parallel queries, then compute scores in JS.
   - Return: `{ properties: [{ id, address, landlordName, healthScore, issues: string[] }], averageScore: N, criticalCount: N }` where criticalCount = properties with score < 50.

3. `GET /pm-overview/agent-activity`
   - Takes optional query params: days (default 7), agentType (optional filter).
   - Query agent_audit_log (check exact table name in schema.ts) grouped by agent_type and action.
   - Return: `{ byAgent: { [agentType]: { totalActions: N, topActions: [{action, count}] } }, totalActions: N, period: { days: N, from: date, to: date } }`

Mount in `server/routes.ts`:
1. Import pmOverviewRouter from './pmOverviewRoutes'.
2. Add `app.use('/api/crm', pmOverviewRouter)` alongside existing route mounts.

Also create `server/__tests__/pmOverview.test.ts` with unit tests:
- Test compliance-alerts response shape: mock pool.query to return sample expired/expiring certs, verify response has `expired`, `expiringSoon`, `totalProperties`, `compliantProperties` fields.
- Test portfolio-health score calculation: mock queries returning 1 expired cert + 2 open maintenance tickets for a property, verify healthScore = 100 - 20 - 10 = 70.
- Test portfolio-health with no issues: verify healthScore = 100.
- Test agent-activity response shape: mock audit_log query returning grouped results, verify `byAgent`, `totalActions`, `period` fields.
- Use vi.mock for pool.query. Import the route handler functions directly or use supertest if available.

IMPORTANT: Grep schema.ts for exact table names before writing SQL. Check: property_certificate vs property_certification, agent_audit_log, maintenance_request, arrears, tenancy, properties, landlords.
