  <files>server/agents/sdk/financeAgent.ts, server/agents/sdk/financeTools.ts</files>
  <action>
    1. Create server/agents/sdk/financeTools.ts with 7 SDK tools using `tool()` from '@openai/agents' and `z as z4` from 'zod4':

       a. `lookupInvoiceStatusTool` -- params: { tenantId?: number, invoiceNumber?: string }. Queries invoices table by tenantId or invoiceNumber. Returns status, amount, dueDate, paidDate. Use lazy import for pool.

       b. `generatePaymentLinkTool` -- params: { invoiceId: number, channel: 'stripe' | 'gocardless' }. Lazy imports paymentService or gocardlessService. Generates payment link for the invoice. Returns link URL. Also sends WhatsApp notification with link via lazy-imported messageSender if contact has WhatsApp.

       c. `queryStatementsTool` -- params: { landlordId?: number, propertyId?: number, period?: string }. Queries landlord_statement table. Returns statement summary (period, status, netPayable). If statement is draft/not yet approved, honestly return "Statement is being reviewed by the accounts team".

       d. `queryRentCollectionTool` -- params: { propertyId: number, months?: number }. Queries paid invoices for a property over last N months. Returns monthly totals.

       e. `queryCostLedgerTool` -- params: { propertyId?: number, landlordId?: number }. Lazy imports and queries the Phase 7 cost ledger API functions (from server/costLedgerRoutes.ts or equivalent). Returns maintenance + compliance cost summary.

       f. `generateReceiptTool` -- params: { invoiceId: number }. Looks up paid invoice, lazy imports pdfService.generateReceiptPDF, generates receipt, stores PDF, returns confirmation.

       g. `escalateToHumanTool` -- reuse the existing escalateToHumanTool from tools.ts via import.

    All tools use lazy imports for pool/services to avoid DB connection at module load. All tools log via auditLogger.

    2. Create server/agents/sdk/financeAgent.ts:
       - Import Agent from '@openai/agents'
       - Import AgentContext from './context'
       - Import all tools from './financeTools' (except escalateToHumanTool which comes from './tools')
       - Define FINANCE_INSTRUCTIONS with Taylor persona:

         * Professional, precise with numbers, transparent about processes
         * British English, no emoji, pounds sterling
         * Tenant queries: invoice status, payment links, receipts
         * Landlord queries: statement status, rent collection, cost queries
         * Transparent on approval: "Your statement is being reviewed by our accounts team" if draft
         * Escalation: if query outside finance scope or tenant expresses difficulty
         * Channel-aware formatting (SMS concise, WhatsApp/email detailed)
         * AI self-identification on first contact
         * IMPORTANT: Taylor does NOT chase overdue rent (Sarah handles that). Taylor does NOT trigger landlord payments (manual by accounts staff).
       - Export `financeAgent` as Agent<AgentContext> with model 'gpt-4o', all tools, FINANCE_INSTRUCTIONS
