<objective>
Build payment commitment capture and payment link dispatch for the arrears chasing workflow.

Purpose: When the arrears agent secures a payment commitment from a tenant, the system must: (1) log the commitment to the audit trail, (2) generate a Stripe or GoCardless payment link and send it to the tenant, and (3) schedule a pg-boss follow-up for the commitment date to verify payment was received. This turns verbal commitments into tracked, actionable payment flows.

Output: PaymentLinkService with Stripe/GoCardless link generation, capturePaymentCommitment and generatePaymentLink tools added to the arrears agent, and pg-boss follow-up scheduling.
</objective>

  <files>

  <behavior>
    - payment-commitment-followup pg-boss worker fires on the commitment date
    - Worker checks if payment was received (query payments table for matching tenant + amount + date range)
    - If payment received: log success to audit trail, update arrears status if fully paid
    - If payment NOT received: check compliance guard, send a follow-up reminder if allowed, schedule another follow-up in 48 hours
    - If payment NOT received and compliance guard blocks (3+ contacts): escalate to human
  </behavior>
  <action>
    1. Update `server/agents/services/scheduledMessages.ts`:
       - Add interface `PaymentCommitmentFollowUpData`:
         * arrearsId: number
         * tenantId: number
         * contactPhone: string
         * channel: 'whatsapp' | 'sms'
         * commitAmount: number (pence)
         * commitDate: string (ISO date)
         * attemptNumber: number (starts at 1)

       - Register worker for 'payment-commitment-followup' queue:
         * On trigger:
           1. Check opt-out via existing checkOptOut method
           2. Check if payment was received: query payments table where tenantId matches, amount >= commitAmount, paidAt between commitDate-1day and commitDate+3days, status='completed'
           3. If payment received:
              - Log success via auditLogger: action='payment_commitment_verified', toolOutput: { arrearsId, amountPaid }
              - Update arrears: if payment covers full outstanding, set status='cleared'; otherwise set status='partially_paid' and reduce amount
              - Do not send any message (payment resolved)
           4. If payment NOT received:
              - Call arrearsComplianceGuard.canContact(tenantId, channel)
              - If allowed: send follow-up message ("We noticed your committed payment of {amount} was due on {date}. Can you confirm when we should expect this?"), log via complianceGuard.logContactAttempt
              - If blocked with reason containing 'escalate': call escalationService.escalate
              - If blocked for other reason (48h window, time-of-day): reschedule for nextAllowedAt
              - If attemptNumber >= 3: escalate regardless
              - Otherwise: schedule another follow-up attempt in 48 hours with attemptNumber + 1

       - Add `schedulePaymentFollowUp(data: PaymentCommitmentFollowUpData, runAt: Date): Promise<string>`:
         * Submit to pg-boss 'payment-commitment-followup' queue
         * Return the job ID
