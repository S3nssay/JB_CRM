  <behavior>
    - Lettings agent receives "What 2-bed flats are available to rent in Clapham?" -> calls search_properties with type='rental', area='Clapham', minBedrooms=2 -> formats response with rent pcm
    - Lettings agent receives "Can I view the flat at 15 Park Road?" -> calls book_viewing -> confirms viewing
    - Lettings agent receives "Nothing available but I'm interested" -> calls create_lead with leadType='rental'
    - Lettings agent formats rent as "£1,850 pcm" (British convention)
    - Lettings agent can negotiate rent based on market data and landlord preferences
    - Follow-up scheduling reuses scheduleFollowUpTool from Sales agent module
  </behavior>
  <action>
    1. Create `server/agents/sdk/lettingsAgent.ts`:
       - Import Agent from `@openai/agents`
       - Import AgentContext from context.ts
       - Import tools: searchPropertiesTool, bookViewingTool, createLeadTool, queryKnowledgeBaseTool, escalateToHumanTool from tools.ts
       - Import scheduleFollowUpTool from salesAgent.ts (reuse, don't duplicate)

       - Create `lettingsAgent` = new Agent<AgentContext>:
         * name: 'Jordan from Lettings'
         * model: 'gpt-4o'
         * instructions: Detailed system prompt including:
           - "You are Jordan, a lettings specialist at John Barclay Estate Agents."
           - Professional-friendly tone, warm but proper
           - No emoji
           - British conventions: rent as "£X,XXX pcm", dates as "1st April 2026", British spelling
           - Match the contact's language
           - Proactively suggest similar rental properties
           - FULL negotiation autonomy -- negotiate rent using market data, property history, landlord preferences
           - Handle multiple properties in one conversation
           - Stale data caveat for 30+ day old data
           - After booking viewing: mention confirmation + 24h reminder + morning-of
           - After lead capture: thank them, schedule follow-ups
           - Channel-aware: SMS concise, WhatsApp full details, email comprehensive
           - Rental-specific: mention deposit amount, tenancy length, available from date where applicable
           - Escalation triggers same as Sales
         * tools: [searchPropertiesTool, bookViewingTool, createLeadTool, queryKnowledgeBaseTool, escalateToHumanTool, scheduleFollowUpTool]
       - Export lettingsAgent

    2. Write tests in `tests/agents/lettingsAgent.test.ts`:
       - Test "enquiry": Verify lettingsAgent has search_properties tool, instructions mention "pcm" and "rental"
       - Test "viewing": Verify book_viewing tool present
       - Test "lead": Verify create_lead tool present; instructions mention leadType rental
       - Test "follow-up": Verify scheduleFollowUpTool is in tools array
       - Test agent name is 'Jordan from Lettings'
       - Test instructions contain negotiation autonomy language
