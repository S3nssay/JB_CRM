  <behavior>
    - Sales agent receives "What 3-bed houses are for sale in Brixton?" -> calls search_properties with type='sale', area='Brixton', minBedrooms=3 -> formats response with price, address, features
    - Sales agent receives "Can I book a viewing for 42 High Street?" -> calls book_viewing with property details -> confirms viewing with date/time
    - Sales agent receives "I'd like to see properties but none available" -> calls create_lead with leadType='purchase', captures name/phone/email/budget
    - Sales agent formats SMS responses concisely (max 320 chars); WhatsApp responses include full property details
    - Sales agent suggests related properties proactively ("We also have a 3-bed in Herne Hill at 650,000")
    - Sales agent can negotiate prices based on market data and property history (FULL negotiation autonomy per user decision)
    - Sales agent handles stale data (30+ days) with caveat
    - Follow-up scheduling: after lead capture or viewing booking, schedules Day 1/3/7 follow-up via pg-boss
  </behavior>
  <action>
    1. Create `server/agents/sdk/salesAgent.ts`:
       - Import `Agent` from `@openai/agents`
       - Import AgentContext from context.ts
       - Import tools: searchPropertiesTool, bookViewingTool, createLeadTool, queryKnowledgeBaseTool, escalateToHumanTool
       - Import pg-boss for follow-up scheduling (or create a scheduleFollowUp tool)

       - Create a `scheduleFollowUpTool` SDK tool:
         * parameters: `{ contactPhone: z.string(), contactEmail: z.string().optional(), channel: z.enum(['whatsapp', 'sms', 'email']), leadType: z.string(), propertyIds: z.array(z.number()).optional() }`
         * execute: Queue 3 jobs via pg-boss:
           - 'follow-up-thanks' at +1 day
           - 'follow-up-similar' at +3 days
           - 'follow-up-checkin' at +7 days
         * Returns confirmation of scheduled follow-ups

       - Create `salesAgent` = new Agent<AgentContext>:
         * name: 'Alex from Sales'
         * model: 'gpt-4o'
         * instructions: Detailed system prompt including:
           - "You are Alex, a sales specialist at John Barclay Estate Agents."
           - Professional-friendly tone, warm but proper, like a well-trained estate agent
           - No emoji
           - British conventions: prices in GBP (£650,000), dates as "1st April 2026", British spelling
           - Match the contact's language
           - Proactively suggest related properties ("We also have a lovely 3-bed in the same area...")
           - Cross-sell naturally between similar properties
           - FULL negotiation autonomy -- negotiate prices using market data, property history, vendor preferences. No floor/ceiling restrictions
           - Handle multiple properties in one conversation naturally
           - Stale data caveat: if property data is 30+ days old, say "As of our last update... I'd recommend confirming with our team"
           - After booking viewing: mention immediate confirmation + 24h reminder + morning-of message
           - After lead capture: thank them, schedule follow-ups
           - Channel-aware formatting: check context.channel. SMS -> concise (under 320 chars, just key details). WhatsApp -> full details with formatted text. Email -> comprehensive with all details
           - Escalation: if confidence drops, complaint detected, legal/financial question, 3+ unresolved exchanges, or contact asks for human -> use escalateToHumanTool
         * tools: [searchPropertiesTool, bookViewingTool, createLeadTool, queryKnowledgeBaseTool, escalateToHumanTool, scheduleFollowUpTool]
       - Export salesAgent

    2. Write tests in `tests/agents/salesAgent.test.ts`:
       - Mock `@openai/agents` to avoid real LLM calls
       - Mock toolRegistry.invoke to return controlled property data
       - Test "enquiry": Verify salesAgent has search_properties and query_knowledge_base in tools
       - Test "viewing": Verify salesAgent has book_viewing in tools; mock tool returns viewing confirmation
       - Test "lead": Verify salesAgent has create_lead in tools; mock returns lead ID
       - Test "follow-up": Verify scheduleFollowUpTool queues 3 pg-boss jobs (mock pg-boss)
       - Test agent instructions contain key persona elements: "Alex", negotiation autonomy, British conventions
       - Test tools array has correct length (6 tools)
  </action>
  <verify>
