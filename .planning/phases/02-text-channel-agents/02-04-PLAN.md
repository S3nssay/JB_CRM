<objective>
Build the Admin specialist agent that generates onboarding/offboarding document checklists, tracks completion, and chases outstanding items.

Purpose: The Admin agent automates the repetitive document management that happens at tenancy start and end. It generates checklists from the existing tenancyChecklistItemMeta schema, tracks which items are complete, chases tenants/landlords for outstanding items, and escalates to staff after 3 failed chases.

Output: Working adminAgent with checklist tools, wired into Supervisor handoffs.
</objective>

  <behavior>
    - checklistService.generateChecklist(tenancyId, 'onboarding') creates checklist items from tenancyChecklistItemMeta where workflow is 'onboarding', 'compliance', or 'general'
    - checklistService.generateChecklist(tenancyId, 'offboarding') creates items where workflow is 'end_of_tenancy'
    - checklistService.getOutstandingItems(tenancyId) returns items where isCompleted=false
    - checklistService.chaseItem(itemId, channel, contactPhone) sends a chase message and logs to audit trail; increments chase count; escalates after 3 chases
    - generateChecklistTool wraps checklistService.generateChecklist
    - chaseChecklistItemTool wraps checklistService.chaseItem
    - Admin agent (Sam from Admin) has tools: generateChecklistTool, chaseChecklistItemTool, escalateToHumanTool
  </behavior>
  <action>
    1. Create `server/agents/services/checklistService.ts`:
       - Import tenancyChecklistItems, tenancyChecklistItemMeta from schema
       - Import db from db.ts
       - Import auditLogger, messageSender, escalationService

       - `generateChecklist(tenancyId: number, workflow: 'onboarding' | 'offboarding')`:
         * Map workflow to meta filters: onboarding -> ['onboarding', 'compliance', 'general'], offboarding -> ['end_of_tenancy']
         * Filter tenancyChecklistItemMeta by workflow
         * Insert each matching item into tenancyChecklistItems with tenancyId, itemType, isCompleted=false
         * Return { created: number, items: string[] }

       - `getOutstandingItems(tenancyId: number)`:
         * Query tenancyChecklistItems where tenancyId matches and isCompleted=false
         * Return array of items with their types and labels

       - `chaseItem(itemId: number, channel: 'whatsapp' | 'sms' | 'email', contactValue: string, tenancyId: number)`:
         * Look up the item to get itemType
         * Look up the label from tenancyChecklistItemMeta
         * Count previous chases for this item from audit log (action='chase', metadata contains itemId)
         * If chaseCount >= 3: call escalationService.escalate({ reason: 'Checklist item overdue after 3 chases', urgency: 'high' })
         * Otherwise: send chase message via messageSender ("We still need your [label] for your tenancy. Please submit at your earliest convenience.")
         * Log chase via auditLogger.logToolCall with action metadata
         * Return { chased: boolean, escalated: boolean, chaseCount }

       - Export singleton checklistService

    2. Add tools to `server/agents/sdk/tools.ts`:
       - `generateChecklistTool` = SDK tool:
         * parameters: z.object({ tenancyId: z.number(), workflow: z.enum(['onboarding', 'offboarding']) })
         * execute: calls checklistService.generateChecklist
       - `chaseChecklistItemTool` = SDK tool:
         * parameters: z.object({ itemId: z.number(), channel: z.enum(['whatsapp', 'sms', 'email']), contactValue: z.string(), tenancyId: z.number() })
         * execute: calls checklistService.chaseItem
       - Export both tools

    3. Create `server/agents/sdk/adminAgent.ts`:
       - Import Agent from `@openai/agents`
       - Import AgentContext from context.ts
       - Import tools: generateChecklistTool, chaseChecklistItemTool, escalateToHumanTool

       - Create `adminAgent` = new Agent<AgentContext>:
         * name: 'Sam from Admin'
         * model: 'gpt-4o'
         * instructions: System prompt including:
           - "You are Sam, an administrative specialist at John Barclay Estate Agents."
           - Professional-friendly tone, warm but proper
           - No emoji
           - British conventions
           - Match contact's language
           - Handles tenancy document management: onboarding checklists, offboarding checklists, document tracking
           - When a new tenancy is created (or contact asks about onboarding): generate onboarding checklist
           - When a tenancy is ending (or contact asks about offboarding): generate offboarding checklist
           - Track outstanding items and chase contacts for missing documents
           - Be helpful about what documents are needed and why
           - Escalation triggers: same as other agents
           - Channel-aware formatting
         * tools: [generateChecklistTool, chaseChecklistItemTool, escalateToHumanTool]
       - Export adminAgent
