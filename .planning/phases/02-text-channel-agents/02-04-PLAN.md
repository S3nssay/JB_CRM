<objective>
Build the Admin specialist agent that generates onboarding/offboarding document checklists, tracks completion, and chases outstanding items. Wire automatic triggers into tenancy creation and status-change routes so checklists are generated without user intervention.

Purpose: The Admin agent automates the repetitive document management that happens at tenancy start and end. It generates checklists from the existing tenancyChecklistItemMeta schema, tracks which items are complete, chases tenants/landlords for outstanding items, and escalates to staff after 3 failed chases. Critically, checklist generation is triggered automatically when tenancy status changes -- not only when a user messages the agent.

Output: Working adminAgent with checklist tools, wired into Supervisor handoffs, with automatic triggers in tenancy routes.
</objective>
