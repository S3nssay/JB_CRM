<objective>
SDK foundation, Supervisor agent, and webhook wiring for the text-channel agent system.

Purpose: Establishes the OpenAI Agents SDK infrastructure that all specialist agents depend on. Installs dependencies, wraps existing Phase 1 tools for SDK consumption, builds the Supervisor triage agent with handoff stubs, creates the escalation service with round-robin staff assignment for human handoff, the unified message sender for outbound replies, wires webhook routes to the ChannelGateway, and connects the existing IMAP email pipeline to the agent system so all three channels flow through the same agent pipeline.

Output: Working Supervisor agent that classifies intent and hands off to specialist stubs, with escalation (including round-robin), audit logging, AI identification, and all three inbound channels (WhatsApp, SMS, email) integrated.
</objective>
