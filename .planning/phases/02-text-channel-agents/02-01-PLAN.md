<objective>
SDK foundation, Supervisor agent, and webhook wiring for the text-channel agent system.

Purpose: Establishes the OpenAI Agents SDK infrastructure that all specialist agents depend on. Installs dependencies, wraps existing Phase 1 tools for SDK consumption, builds the Supervisor triage agent with handoff stubs, creates the escalation service for human handoff, the unified message sender for outbound replies, and wires webhook routes to the ChannelGateway so real inbound messages flow through the agent pipeline.

Output: Working Supervisor agent that classifies intent and hands off to specialist stubs, with escalation, audit logging, and AI identification integrated.
</objective>
