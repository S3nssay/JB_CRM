## FOUNDATION INFRASTRUCTURE (Phase 01 — In Development)

### Schema Foundation & Testing Infrastructure
- **Property Systems Inventory** table — Track heating, electrical, plumbing, ventilation, fire safety, security systems per property (make, model, serial, warranty, service dates)
- **Agent Audit Log** table — Immutable trail of every AI agent action (tool calls, classifications, routing decisions, escalations)
- **Contact Identities** table — Cross-channel identity resolution (same person across SMS, WhatsApp, email, phone)
- **Extended Conversations** table — AI agent metadata fields (source, agentType, contactType, lastChannel, resolvedContactId)
- **Extended Messages** table — AI message tracking (agentType, toolCalls JSON, isAiGenerated flag)
- **Vitest Testing Framework** — Unit/integration test infrastructure with TypeScript path aliases

### Channel Gateway & Multi-Channel Threading
- **Channel Gateway** — Normalises inbound SMS and WhatsApp messages, resolves contacts, threads into conversations
- **SMS Adapter** — Parses Twilio SMS webhook payloads into normalised message format
- **WhatsApp Adapter** — Parses Twilio WhatsApp webhook payloads (strips `whatsapp:` prefix)
- **Contact Resolver** — Resolves phone/email to existing tenant, landlord, or lead records with E.164 normalisation
- **Conversation Store** — Persistent conversation threading, message storage, history retrieval
- **Cross-Channel Identity** — Same phone number via SMS and WhatsApp resolves to same contact

### Tool Registry & CRM Action Tools
- **Tool Registry Framework** — Registers, validates (Zod), permission-checks, and dispatches tool calls for AI agents
- **OpenAI Function Schema Export** — Converts registered tools to OpenAI function-calling format per agent type
- **search_properties** tool — Agents search CRM properties by area, postcode, type, bedrooms, price
- **query_knowledge_base** tool — Agents query certifications, systems inventory, and maintenance history per property (<100ms)
- **create_lead** tool — Agents create new CRM leads with scoring and source tracking
- **create_maintenance_ticket** tool — Agents create maintenance tickets with category and priority
- **book_viewing** tool — Agents book property viewings with contact details and preferred dates

### Agent Audit Logging & UK Compliance
- **Audit Logger Service** — Logs every agent action (tool_call, classify, route, escalate, respond) to `agent_audit_log`
- **Sensitive Data Redaction** — Passwords, tokens, secrets, and keys are redacted before audit logging
- **Fire-and-Forget Logging** — Audit failures never break agent operations (errors caught, logged to console)
- **Registry-to-Audit Wiring** — Every Tool Registry invocation automatically logged with input, output, and duration
- **AI Self-Identification Middleware** — First outbound AI message prefixed with UK-compliant self-identification statement
- **Conversation-Aware Identification** — Subsequent messages in same conversation are NOT prefixed (avoids repetition)

### Property Knowledge Base UI (CRM Page)
- **Certifications Tab** — View all property certifications with type, status badges (valid/expiring/expired), expiry dates
- **Systems Inventory Tab** — View, add, and edit systems inventory entries (heating, electrical, plumbing, etc.)
- **Maintenance History Tab** — View last 20 maintenance tickets with category, priority, and status
- **API Endpoints** — GET aggregated KB, GET/POST/PUT systems inventory per property
- **CRM Navigation** — Accessible from Property Management section in CRM sidebar
